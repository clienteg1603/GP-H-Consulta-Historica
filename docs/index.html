O que o programa oferece

Uma interface direta para pesquisar e acompanhar o histórico salvo localmente no computador.

Pesquisa histórica

Consulte resultados por período, sorteio, prêmio, bicho, grupo, dezena, centena e milhar.

Jogos do dia

Visualize as extrações do dia de forma organizada e navegue pelo calendário.

Atrasos e estatísticas

Acompanhe indicadores históricos, frequências, atrasos e rankings para estudo.

Base local

Os resultados ficam armazenados no próprio computador após a sincronização.

Atualização pela internet

O programa consulta novos resultados para manter o histórico atualizado.

Executável pronto

O pacote já vem compilado para Windows e não exige instalação do Python.

Primeira utilização

A primeira carga foi pensada para funcionar também em um computador onde o GP-H nunca foi usado.

Baixe o ZIP oficial e extraia o conteúdo para uma pasta.

Abra GP-H Consulta Historica.exe.

Na primeira execução, o programa cria a base local e inicia a sincronização dos resultados do Rio de Janeiro desde 02/01/2026.

Depois da carga inicial, as atualizações passam a buscar apenas os dados novos ou necessários para manter a base atualizada.

Importante: os resultados utilizados pelo programa são referentes ao Rio de Janeiro. Resultados de outras localidades, estados, praças ou bancas podem ser diferentes. Estatísticas e resultados históricos não garantem resultados futuros.
